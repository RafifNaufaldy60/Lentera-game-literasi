# Paket Aset Cyber Shop

Paket visual untuk toko digital Lentera PLAY. Semua aset disimpan lokal dan dioptimalkan agar katalog tidak perlu mengunduh gambar dari layanan eksternal.

| File | Kegunaan | Resolusi |
| --- | --- | --- |
| `frontend/public/shop/frame.webp` | Avatar frame (dua opsi warna / ring CSS) | 448×448 |
| `frontend/public/shop/chat.webp` | Chat theme (dua palet CSS) | 448×448 |
| `frontend/public/shop/companion.webp` | Companion Neko Byte dan Aurora Bot | 448×448 |
| `frontend/public/shop/background.webp` | Wallpaper Moon City dan Neon Skyline | 448×448 |
| `frontend/public/shop/nameplate.webp` | Preview item gelar | 448×448 |
| `frontend/public/shop/stickers.webp` | Preview koleksi stiker | 448×448 |
| `frontend/assets/cyber-shop-asset-sheet.png` | Lembar karya asli 3 kolom × 2 baris | 1536×1024 |

Gambar kartu toko memang memiliki latar navy karena karya aslinya berupa ilustrasi item pada panel cyber. Pemasangan kosmetik pada UI dilakukan dengan CSS/komponen React agar avatar asli tetap terlihat dan loading ringan.

Aset game adalah ilustrasi orisinal khusus Lentera; tidak menggunakan screenshot, logo produk komersial, atau potongan karakter game lain.
